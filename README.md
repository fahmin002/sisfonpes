# 🕌 Sistem Informasi Pondok Pesantren Darul Amin

Sistem Informasi Pendaftaran dan Manajemen Santri berbasis web yang digunakan oleh Pondok Pesantren Darul Amin untuk mendigitalisasi proses penerimaan santri, manajemen data santri, dan administrasi internal pesantren.

Aplikasi ini dibangun menggunakan **Laravel**, **Inertia.js**, dan **React** dengan autentikasi menggunakan **Laravel Fortify**. Sistem ini mendukung upload bukti pembayaran, validasi data santri, serta dashboard administrator untuk mengelola pendaftaran.

---

## ✨ Fitur Utama

- 📌 **Pendaftaran Santri Online**
- 🧾 Upload **bukti pembayaran (QRIS / Transfer / PDF / Gambar)**
- 🧑‍🏫 **Dashboard Admin**
- 🔐 **Autentikasi Admin (tanpa public registration)**
- 🧭 Manajemen Data Santri Terdaftar
- 📋 Edit dan Validasi Pendaftaran
- 📁 Preview file image/pdf di halaman admin

---

| Teknologi | Keterangan |
